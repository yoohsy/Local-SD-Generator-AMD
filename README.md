# Local SD Generator (AMD UI)

Графическая оболочка (Windows Forms) для консольного движка `stable-diffusion.cpp`. Позволяет генерировать изображения на видеокартах AMD через Vulkan без использования командной строки.

## Требования
- Windows 10/11
- Видеокарта AMD с поддержкой Vulkan (тестировалось на RX 5700 XT)
- [.NET Desktop Runtime](https://dotnet.microsoft.com/download/dotnet) (если собираешь не Self-contained версию)
- Скачанный движок `stable-diffusion.cpp` (сборка `win-vulkan-x64`)

## Как запустить
1. Скачай архив с релизом (или собери проект сам).
2. Скачай сборку `stable-diffusion.cpp` для Windows с Vulkan с [официального репозитория](https://github.com/leejet/stable-diffusion.cpp/releases).
3. Распакуй движок в папку `engine` рядом с `.exe` файлом программы. Убедись, что внутри лежит `sd-cli.exe` и `.dll` файлы.
4. Запусти программу.
5. Нажми "Выбор модели" и укажи путь к файлу `.gguf` или `.safetensors`.
6. Введи промпт и нажми "Сгенерировать".

## Фичи
- Выбор модели и LoRA через проводник (пути хранятся в памяти во время сессии).
- Настройка разрешения, шагов (Steps), CFG и фиксированного сида (Seed).
- Кнопка выбора папки сохранения. Путь записывается в `settings.ini` рядом с `.exe` и не сбрасывается после перезапуска.
- Включение/отключение LoRA галочкой.

## Ограничения
- На картах с 8 ГБ VRAM (RX 5700 XT) разрешение выше 768x1024 может привести к вылету из-за нехватки видеопамяти (OOM).
- Жесткий путь к движку: по умолчанию программа ищет `sd-cli.exe` по пути из исходного кода. Если переносишь папку, поменяй путь в `Form1.cs` (переменная `FileName`) или положи движок в папку `engine` рядом с программой.
